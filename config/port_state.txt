# The native port's files in the link's three groups (docs/NETPLAY.md,
# "State apart from presentation"), read by tools/port_build.py and
# tools/port_sdl_build.py:
#
#   state     its variables are the game's state: saved, put back, hashed
#             in part and run again (include/port_state.h);
#   run       state as well, but the run's own, never carried into another
#             run: linked last in the state, and a replay's start
#             (include/port_replay.h) keeps this run's own there;
#   outside   its variables are the picture's, the run's output, the
#             host's or the snapshot's own: never put back by a load, so
#             a counter of theirs only goes forward.
#
# The game's own files (src/main/, src/rebushido/, Sony's, the movie's) are
# state, always, and are linked first in each kind. Every file of
# src/port/ and every file of src/port/window/ that is linked into the
# game's object is one line here, or the build stops: a new file is put
# in one group or the other when it is written. The rest of the window
# (sdl_*.c) and src/port/gl/ are outside by being outside the game's
# object; SDL and the C library likewise.
#
# A file's variables are all in its group. A variable of a state file
# that must not be put back by a load goes in a file that is outside.
